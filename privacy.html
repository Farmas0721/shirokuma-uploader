プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-11-09

1. 対象 / Scope

本ポリシーは、個人用ツール「shirokuma-uploader」（以下「本ツール」）に適用されます。本ツールは、しろくまチャンネルの運営者が自分の YouTube チャンネルへ動画をアップロードするためだけに使います。

This policy applies to "shirokuma-uploader", a personal tool used solely by the owner of the Shirokuma Channel to upload videos to their own YouTube channel.

2. 取得する情報 / Information accessed

本ツールは Google の OAuth 認証で youtube.upload 権限のみを要求し、運営者自身のチャンネルへ動画・サムネイル・タイトルなどのメタデータをアップロードします。それ以外の Google アカウント情報や、視聴者の個人情報は取得しません。

The tool requests only the youtube.upload scope and uses it to upload videos, thumbnails and their metadata to the owner's own channel. It does not access any other Google account data or any personal data of viewers.

3. 保存と共有 / Storage and sharing

認証トークンは運営者のコンピュータ上にのみ保存され、外部のサーバーには送信しません。取得した情報を第三者に提供・販売することはありません。

The OAuth token is stored only on the owner's local computer and is never sent to any server other than Google's. No data is shared with or sold to third parties.

4. 権限の取り消し / Revoking access

アクセス権は Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。

Access can be revoked at any time from Google Account > Third-party apps & services.

5. Google API サービスの利用 / Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses the YouTube API Services, subject to the YouTube Terms of Service and the Google Privacy Policy.
